# Returing
Este é um projeto de jogo para o IFSP - SPO, para todas as disciplinas do núcleo técnico. 

Returing é um jogo topdown de ação e puzzles, onde você joga com Alan Turing em uma Terra devastada por uma IA criada pelo próprio Turing, no ano de 1945.

Projeto feito por: Gustavo Henrique, Alice Bettin, Eduarda Moniz, Icaro Francioni e Ana Beatriz.

## Como testar
- Jogo completo: `Scenes/Start/menu_start.tscn` (F5): Menu → Cutscene → Fase 1 (3 ondas).
- Fase 1 direto (ondas): `Scenes/Fase1/fase_1.tscn` (F6).
- Auditoria de arquitetura (refs, camadas, EventBus): `tests/audit/architecture_audit.tscn` (F6).
- Testes de unidade: `tests/test_runner.tscn` (F6, 198 checagens, resultado no Output).
- Teste de integração ponta a ponta: `tests/integration/flow_test.tscn` (F6, 89 checagens, ~1–2 min).
- Arena do inimigo de treino: `tests/dummy_arena/teste_dummy.tscn` (F6).
- Configuração do editor e arquitetura: `GUIA_CONFIGURACAO_EDITOR.md`. Histórico: `CHANGELOG.md`.
