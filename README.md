# Returing

Este é um projeto de jogo para o IFSP-SPO, desenvolvido para todas as disciplinas do núcleo técnico.

Returing é uma aventura indescritível em que você, jogador, assume o controle de um estudante chamado pelo próprio Alan Turing para instalar o módulo ético A.E.G.I.S em uma I.A. corrompida que destruiu o mundo inteiro.

## Construído com

- **Godot**: engine utilizada no projeto;
- **HTML5**: linguagem utilizada para fazer o site;
- **Android SDK**: adequação para mobile;
- **dotpict**: criação dos sprites.

## Instalação

Todos os arquivos estão disponíveis no [Google Drive](https://drive.google.com/drive/u/1/folders/1NQpKEup4KyXYShkUSw1h4h0qpZFMBoE9).

### Windows

Procure no link do Google Drive o arquivo para Windows, extraia no seu computador e execute o arquivo `.exe`.

### Linux

Procure no link do Google Drive o arquivo para Linux, extraia no seu computador e execute o arquivo.

### Android

Procure no link do Google Drive o arquivo para Android, permita a instalação de fontes desconhecidas e abra o aplicativo.

## Requisitos operacionais

- Arquitetura de 64 bits;
- 2 GB de memória RAM;
- 100 MB de armazenamento livre no sistema.
